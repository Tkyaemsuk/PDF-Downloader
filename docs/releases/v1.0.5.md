## PDF Downloader 1.0.5 — Large documents

แก้ข้อผิดพลาด **เอกสารมีขนาดใหญ่เกินไป** ที่เกิดจากการสร้าง canvas ยาวทั้งเอกสาร โดยเปลี่ยนเป็นจับภาพและประกอบ PDF ทีละหน้า

### เปลี่ยนแปลง

- เก็บสำเนา DOM คงที่ก่อนส่งออก และจับภาพเฉพาะพื้นที่ของแต่ละหน้า
- ไม่ติดข้อจำกัดเดิม 16,000 px / 32 ล้านพิกเซลของเอกสารรวม
- จำกัดภาพที่จับแต่ละหน้าไว้ไม่เกิน 3,000 px ต่อด้าน / 6 ล้านพิกเซล; ปรับความละเอียดอัตโนมัติเมื่อจำเป็น
- คืน canvas และข้อมูลภาพที่ถอดรหัสหลังใส่ลง PDF แต่ละหน้า
- รองรับสูงสุด 500 หน้า พร้อมความคืบหน้าระหว่างสร้างและล้างทรัพยากรเมื่อเกิดข้อผิดพลาด
- ใช้การจัดหน้า โลโก้ ลายน้ำ ท้ายกระดาษ และ selector เดิมได้

### อัปเดต

ดาวน์โหลด `pdf-downloader-1.0.5.tar.gz` จาก Assets อัปโหลดใน Plugins แล้วรีเฟรชหน้า Design ด้วย Ctrl+Shift+R และทดสอบใน Preview ไม่ต้องเปลี่ยน selector เดิม

สำหรับแบบฟอร์มหลายชุด ใช้ **แบบฟอร์มแยกหน้า — หนึ่งชุดต่อหน้า**; สำหรับรายงานต่อเนื่อง ใช้ **หลายหน้า** หรือ **อัตโนมัติ**

![ตัวอย่างการตั้งค่า selector ซึ่งยังใช้ได้กับ 1.0.5](https://raw.githubusercontent.com/Tkyaemsuk/PDF-Downloader/main/docs/images/settings-guide.png)

### การทดสอบและขอบเขต

ทดสอบแบบฟอร์ม 16 ชุดที่ quality 3 (เทียบเท่าภาพรวมสูง 57,600 px / ประมาณ 138 ล้านพิกเซลในระบบเดิม) และเอกสารต่อเนื่องสูง 20,000 CSS px รวมการตรวจส่วนลงชื่อ/หน้าสุดท้ายและขนาด canvas

ไฟล์ PDF รวมและ DOM ยังใช้หน่วยความจำตามจำนวนข้อมูล เอกสารใหญ่ใช้เวลามากขึ้นและไม่ได้รับประกันว่า 500 หน้าจะทำงานได้บนทุกอุปกรณ์ PDF ยังเป็นภาพและส่งออกเฉพาะข้อมูลที่ render แล้ว
