## PDF Downloader 1.0.4

แก้การส่งออกเอกสารที่ประกอบด้วยหลายแบบฟอร์ม: ก่อนหน้านี้ปลั๊กอินตัดภาพเอกสารรวมตามความสูงกระดาษ จึงอาจทำให้ส่วนลงชื่อของชุดถัดไปหลุดไปอีกหน้า และปรับโลโก้เฉพาะชุดแรก

### ใหม่

- **แบบฟอร์มแยกหน้า — หนึ่งชุดต่อหน้า**: กำหนดขอบเขตด้วย class `pdf-page` หรือ CSS selector ของ Container แต่ละชุด
- รวมส่วนหัว เนื้อหา และส่วนลงชื่อของแต่ละชุดไว้ในกระดาษเดียว โดยกันพื้นที่ท้ายกระดาษก่อน
- ปรับสัดส่วนโลโก้ทุกชุด; ใช้ `pdf-logo` เพื่อระบุรูปที่ต้องการ
- รองรับ `pdf-header`, `pdf-signatures`, `pdf-keep` และ `pdf-break-before`
- ไม่รวมช่องว่างระหว่าง Container และไม่แก้ DOM ต้นฉบับ

### วิธีใช้กับเอกสารสองชุด

1. อัปโหลด `pdf-downloader-1.0.4.tar.gz` ใน Plugins แล้วรีเฟรช Design
2. ใส่ class `pdf-page` บน Container แต่ละชุด ซึ่งต้องรวมส่วนลงชื่อด้วย หากไม่มีช่อง class ให้ระบุ selector ของ Container สองตัวแทน
3. เลือก **การจัดหน้า PDF → แบบฟอร์มแยกหน้า — หนึ่งชุดต่อหน้า**
4. ตั้ง **CSS selector ของหน้าแบบฟอร์ม** เป็น `.pdf-page` หรือ selector ของ Container ที่ต้องการ แล้วทดสอบใน Preview

ห้ามเลือก Container เอกสารรวมเป็น page เดียวหากต้องการสองหน้า และไม่ควรเลือก page ที่ซ้อนกัน โหมดนี้ส่งออกเฉพาะ Container ที่เลือก เนื้อหานอก Container ไม่ถูกรวม

### ภาพและค่าตัวอย่างการตั้งค่า

![คู่มือตั้งค่า PDF Downloader 1.0.4](https://raw.githubusercontent.com/Tkyaemsuk/PDF-Downloader/main/docs/images/settings-guide.png)

ภาพสรุปอ้างอิงตัวอย่างผู้ใช้ ไม่ใช่ภาพหน้าจอ Budibase โดยตรง

- ช่องบนสุด **CSS selector ของเอกสาร**: เว้นว่าง เมื่อเอกสารอยู่ภายในปลั๊กอิน
- **การจัดหน้า PDF**: แบบฟอร์มแยกหน้า — หนึ่งชุดต่อหน้า
- **CSS selector ของหน้าแบบฟอร์ม**: ใส่ค่าด้านล่าง แล้วกด Save

```css
[data-name="Container 55"], [data-name="Container 30"]
```

ชื่อ Container ต้องตรงกับแอปจริง และแต่ละ Container ต้องรวมส่วนลงชื่อ จากนั้นทดสอบใน Preview ไม่ต้องนำ selector นี้ไปกรอกในช่อง selector เอกสารบนสุดหรือ Custom CSS

### ตรวจสอบ
