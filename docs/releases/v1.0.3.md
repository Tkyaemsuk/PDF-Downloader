## PDF Downloader 1.0.3

ปลั๊กอินสำหรับ **Budibase 3.4.1** พัฒนาด้วย **Svelte 3.59.2** ส่งออกเอกสารเป็น PDF พร้อมจัดหน้า โลโก้ ลายน้ำ และท้ายกระดาษ

### สิ่งใหม่ในเวอร์ชันนี้

- โลโก้ส่วนหัวรักษาสัดส่วนจริง ไม่ยืดหรือบีบ และไม่ขยายเกินพื้นที่เดิม
- ตั้งขนาดสูงสุดโลโก้ได้ ค่าเริ่มต้น 28 × 20 มม.
- เลือกโลโก้โดยอัตโนมัติ หรือระบุ CSS selector ผ่าน Settings
- ปรับภาพเฉพาะสำเนาที่ใช้สร้าง PDF ไม่แก้หน้าจอ Budibase เดิม

รวมการแก้ไขจาก 1.0.1–1.0.2: ปุ่มแสดงผลตามชื่อ component ที่ถูกต้อง และโหมดพอดีหนึ่งหน้าสำหรับแบบฟอร์มที่มีส่วนลงชื่อ

### ติดตั้ง / อัปเดต

1. ดาวน์โหลด **pdf-downloader-1.0.3.tar.gz** จาก Assets ด้านล่าง (ไม่ใช่ Source code)
2. อัปโหลดไฟล์โดยไม่แตกไฟล์ในหน้า Plugins ของ Budibase
3. รีเฟรชหน้า Design ด้วย Ctrl+Shift+R และทดสอบใน Preview

สำหรับแบบฟอร์มหน้าเดียว เลือก **การจัดหน้า PDF → พอดีหนึ่งหน้า — รวมส่วนลงชื่อ** สำหรับโลโก้ เปิด **ปรับสัดส่วนโลโก้ส่วนหัว** และระบุ selector หากรูปแรกไม่ใช่โลโก้

### การตรวจสอบ

- Build สำเร็จด้วย Svelte 3.59.2
- Unit tests 6 รายการ และ browser tests 6 รายการผ่าน
- ตรวจการดาวน์โหลด PDF, page bounds, component registration และสัดส่วนโลโก้
- ตรวจ SHA-256 ได้ด้วยไฟล์ **SHA256SUMS** ที่แนบ

### ข้อจำกัด

PDF เป็นภาพ ข้อความจึงเลือกหรือค้นหาไม่ได้ ส่งออกเฉพาะข้อมูลที่ render แล้วในหน้าจอ รูปภายนอกต้องรองรับ CORS และฟอนต์ไทยต้องโหลดได้ การทดสอบอัตโนมัติไม่ได้ครอบคลุมทุกแอปหรือ theme บน Budibase จริง
